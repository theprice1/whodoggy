A mobile and web application to scan dog microchips via QR and identify owners using cross-database lookup.

---

## Tech Stack

- **Mobile:** React Native (Expo)
- **Web:** React
- **Backend:** Express + PostgreSQL
- **Authentication:** Firebase Authentication
- **Styling:** NativeWind (Tailwind CSS for React Native) and Tailwind CSS for web

---

## Features

- Mobile app with QR scanner to scan dog microchips
- Cross-database lookup of microchip IDs to identify owners
- User authentication with Firebase
- Responsive web frontend for user account management and lookup
- Backend API built with Express and PostgreSQL to serve data securely

---
