# 📱 Apps

This folder contains the frontend applications for WhoDoggy, built for both mobile and web platforms.

## Subfolders

- `mobile/` – React Native app using Expo and NativeWind, designed for QR code scanning and displaying dog identity info.
- `web/` – React web app using Tailwind CSS, focused on manual microchip lookup and accessible UI.

Both apps share types and Firebase config from the `packages/shared/` workspace.
