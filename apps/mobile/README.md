# WhoDoggy Mobile App

This is the React Native mobile app for WhoDoggy, built with Expo.

## Features

- QR code scanning to read dog microchip data.
- Firebase Authentication integration.
- NativeWind and Tailwind CSS for styling.
- Offline and online support.

## Requirements

- Node.js >= 18
- Expo CLI
- pnpm package manager
