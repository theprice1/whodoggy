# Legal, Ethical, Social, and Professional Design (LESP)

This project has been designed with the LESP framework in mind.

## Legal
- Simulated compliance with data protection (GDPR-inspired mock terms)
- Transparent, mock Terms of Use and license

## Ethical
- Respect for guide/service dogs
- Clear guidelines to prevent scanning misuse
- In-app educational screens for responsible use

## Social
- Inclusive design: readability, accessibility, feedback collection
- Transparency through help documentation and app disclaimers

## Professional
- Licensed under MIT
- TypeScript used throughout
- Linting and formatting enforced via ESLint
- Git-based version control with proper commit messages
