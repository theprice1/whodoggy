# WhoDoggy Backend API

Node.js Express backend for WhoDoggy.

## Features

- REST API with PostgreSQL database.
- Firebase Admin SDK integration for authentication.
- Rate limiting, CORS, and error handling middleware.
- Sentry for error tracking.

## Requirements

- Node.js >= 18
- PostgreSQL server running
- pnpm package manager

## Setup

1. Install dependencies:

```bash
pnpm install
