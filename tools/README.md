# WhoDoggy Tools

This folder contains utility scripts and automation tools to support development, testing, and deployment of the WhoDoggy project.

## Structure

- `openapi/`: Generate TypeScript types and clients from the OpenAPI spec.
- `scripts/`: General utility scripts for database seeding, syncing, cleanup, etc.
- `ci/`: Helper scripts for continuous integration and deployment.

## Usage

Run scripts using `ts-node` or compile them with TypeScript before running. Each subfolder contains its own README with detailed usage instructions.
